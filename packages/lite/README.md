<h1 align="center">Lite package</h1>

Compatibility wrapper for projects migrating from the v2 Lite composer.
Version 3 re-exports the lean `@santi020k/eslint-config-basic` API; new projects
should install and import the Basic package directly.

> [!WARNING]
> Deprecated in v3 and scheduled for removal in v4. Replace this package with
> `@santi020k/eslint-config-basic`.

Package: `@santi020k/eslint-config-lite`.

## Recommended replacement

See the [migration guide](https://eslint.santi020k.com/guide/migration-v2-to-v3/) for the
copy-paste installation and configuration steps for your project.

## Compatibility

- Node.js: `>=22.19.0`
- ESLint: `^10.0.0`
- ESM and ESLint flat config
