Use Hono support from the lean v3 composer. Install the `@santi020k/eslint-config-hono` package.

## Install


<InstallTabs packages={["@santi020k/eslint-config-basic", "@santi020k/eslint-config-hono", "eslint"]} />


## Configure

```js
import { defineConfig } from '@santi020k/eslint-config-basic'

export default await defineConfig({
  frameworks: {
    hono: true
  },
  typescript: true
})
```

With the required config packages installed, the one-line recommended entry auto-detects the framework; custom configs can use `defineConfig()` without a `frameworks` object.

## What It Adds

- Hono and edge runtime rules.
- Composition through the same `@santi020k/eslint-config-basic` entry point as every other framework.
- Compatibility with advanced overrides if you pass a custom config array or factory instead of `true`.

## Notes

- This framework package is a public, optional dependency in v3; the basic composer loads it only when enabled.
- For the archived v1 setup, see the [v1 Hono guide](/v1/frameworks/hono).
