Use React Router v7 (framework mode) support from the lean v3 composer. This config is the successor to the [Remix config](/frameworks/remix), since Remix merged into React Router v7.

## Install


<InstallTabs packages={["@santi020k/eslint-config-basic", "@santi020k/eslint-config-react", "@santi020k/eslint-config-react-router", "eslint"]} />


## Configure

```js
import { defineConfig } from '@santi020k/eslint-config-basic'

export default await defineConfig({
  frameworks: {
    react: true,
    'react-router': true
  },
  typescript: true
})
```

With the required config packages installed, the one-line recommended entry auto-detects the framework; custom configs can use `defineConfig()` without a `frameworks` object.

## What It Adds

- Recommended accessibility rules from `eslint-plugin-jsx-a11y` for route components.
- Adjustments that prevent false positives in virtual script blocks generated by the framework.
- Composition through the same `@santi020k/eslint-config-basic` entry point as every other framework.
- Compatibility with advanced overrides if you pass a custom config array or factory instead of `true`.

## Notes

- Migrating from Remix? Enable `'react-router'` instead of `remix` — the rule coverage carries over.
- Pair this config with the [React config](/frameworks/react) — auto-detection handles this for you.
- This framework package is a public, optional dependency in v3; the basic composer loads it only when enabled.
