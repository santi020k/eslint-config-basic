---
title: "Migrate Remix to React Router"
description: "Use the React Router v7 ESLint configuration for Remix projects in v3."
---

Remix merged into React Router v7. Version 3 removes the deprecated
`@santi020k/eslint-config-remix` package and `frameworks.remix` option.

## Install

```sh
npm remove @santi020k/eslint-config-remix
npm install -D @santi020k/eslint-config-react-router@^3 @santi020k/eslint-config-react@^3
```

## Configure

```diff
 import { defineConfig } from '@santi020k/eslint-config-basic'

 export default await defineConfig({
   frameworks: {
-    remix: true
+    'react-router': true
   }
 })
```

Projects that still declare `@remix-run/react` or `@remix-run/node` are
auto-detected and receive the React Router configuration.

See the [React Router guide](/frameworks/react-router) for the current rule set,
or the [v2 Remix guide](/v2/frameworks/remix) for the frozen legacy API.
