## Moving from v1

The website release does not change the package migration contract. Existing v1 users should follow the [v1-to-v2 migration guide](/guide/migration-v1-to-v2/) and use `migrate --write` only after reviewing the proposed framework changes.

For package-level release notes, continue to the [changelog index](/guide/changelog/).
