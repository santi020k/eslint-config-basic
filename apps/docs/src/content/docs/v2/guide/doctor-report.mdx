Use the report viewer when adoption, migration, or a workspace move leaves the active ESLint setup unclear. It recognizes the JSON contract emitted by `doctor --json` and links common findings to focused fixes.

<DoctorReportViewer />

## What the viewer understands

- Missing or unloadable flat-config files.
- Remaining v1 framework imports.
- Missing lint scripts and incomplete workspace scoping.
- Duplicate ESLint installations.
- Missing packages in Lite setups.

For runtime rule matching and precedence, continue with the [Inspector guide](/v2/guide/inspector/). For problems that are not represented in the doctor report, use [Troubleshooting](/v2/guide/troubleshooting/).
